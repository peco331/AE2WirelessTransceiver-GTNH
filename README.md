# AE2 Wireless Transceiver (GTNH) · AE2 无线收发器

为 GTNH 添加**按名称配对的无线收发器**，把基地的 ME 网络连接到远处的机器、仓库或其他维度。两端各放一个方块、接上 ME 线缆、选同一个频率即可使用，也支持多台收发器互连。

**适用 Minecraft 1.7.10，支持 GTNH 2.9.0 RC1 与 beta3。RC1 已由玩家实测正常使用。**

[下载](https://github.com/peco331/AE2WirelessTransceiver-GTNH/releases/latest) · [更新日志](CHANGELOG.md) · [技术文档](docs/TECHNICAL.md) · [反馈问题](https://github.com/peco331/AE2WirelessTransceiver-GTNH/issues)

## 功能

- **无线连接 ME 网络**：默认支持跨维度，无距离限制；收发器本身不占频道，具有 32 频道容量。
- **名称配对**：同一玩家放置的收发器，设为同一个频率即可互连，无需区分主从端或放入配对奇点。
- **频率管理**：支持搜索、新建、设定、断开和删除。这里的“频率”是配对名称（类似 AE2 P2P 通道的频率），与 AE2 的“频道”不同。
- **定位收发器**：在界面中列出同一频率的全部收发器，可在世界中透视高亮其中一台、几台或全部，并在聊天栏生成可点击的传送坐标；其他维度的收发器同样会被标记，进入该维度即可看到。
- **收发器命名**：每台收发器可以单独起名，列表、定位提示和 Waila 都显示名字；铁砧改过名的收发器放下时直接使用该名字。
- **网络状态显示**：通过 Waila、方块界面和 AE2 网络可视化工具查看连接与频道信息。
- **扳手操作**：右键锁定 / 解锁，潜行右键拆卸；已锁定设备由所有者或管理员管理。
- **外观**：玻璃机壳，内部是带物理效果的黑洞，周围的光点显示整个频率的频道用量（本机那部分更亮）和频率负载；玻璃上有 AE2 量子环式电弧。深色、浅色两套配色，每台可在界面里单独切换。也可以改用普通方块外观，或装上旧版外观材质包（见下文）。
- **语言**：简体中文、繁体中文和英文。

## 安装

将 `ae2wtx-*.jar` 放入 `mods` 文件夹，更新时移走旧版。联机时客户端与服务端都需要安装。

必需依赖为 **AE2（GTNH 分支）和 GregTech 5 Unofficial**；Waila 提供方块信息提示。直接使用整合包自带的依赖即可。

当前构建依赖沿用 beta3 基线，具体版本见[技术文档](docs/TECHNICAL.md)；这不表示只能在 beta3 使用。

## 合成与使用

**8 个 ME 量子环 + 1 个 ME 量子链接仓 → 1 个无线收发器**，量子链接仓放在工作台中央。

1. 在基地和远端各放一台收发器，用 ME 线缆连接各自的网络设备。需要互连的收发器应由**同一玩家放置**。
2. 右键基地收发器，输入名称（例如 `mining`），点击 **新建**。
3. 打开远端收发器，选择 `mining`，点击 **设为当前**。
4. 保持两端区块加载，并保证 ME 网络供电和频道充足。

**收发器** 按钮切换到该频率的收发器列表，选中后点 **定位** 高亮（不选则高亮全部，默认 60 秒后消失，可在配置中调整）；在频率列表直接点 **定位** 会高亮当前显示频率的全部收发器。聊天栏中的坐标可点击填入传送命令（装有 ServerUtilities 时使用可跨维度的 `/tpl`）。

**断开**只让本机退出；**删除**会删除整个频率并断开关联收发器，仅所有者或管理员可执行。

界面标题栏右上角有两个小按钮：铅笔按钮给这台收发器命名（回车或再点一次保存，Esc 取消，清空即删除名字；已锁定的收发器只有所有者或管理员能改）；另一个切换这台收发器的外观：跟随默认 → 深色 → 浅色。用扳手拆下时，名字和选过的外观都会跟着物品走；用镐子挖掉则不保留。

已不存在的收发器（旧版本遗留或被外部工具删掉的方块）会在所在区块加载后自动从列表中清除。

### 收发器外观

- 工作时，黑洞周围 8 个光点代表频率的全部容量（32 频道时每个光点 4 个频道）：亮起的数量是整个频率已用的频道，其中本机承担的那部分更大更亮，其余较暗。光点颜色表示整个频率的负载：紫色正常，橙色超过 75%，红色已满。
- 想看清内部，可在配置里调低接线面板的不透明度（`panelOpacity`），或关闭玻璃电弧（`glassArcs`）。
- 离线时，黑洞变暗，光点和玻璃上的电弧熄灭。

## 使用要点

- 无线连接仍遵守 AE2 的频道、供电与安全权限规则。普通线缆的 8 频道瓶颈仍然存在，需要 32 频道路径时使用致密线缆。
- 默认每台收发器消耗 **10 AE/t**，不随距离增加；本模组不提供区块加载功能。
- 不同玩家的同名频率互不相通，当前没有 FTB Teams 队伍共享。关闭跨维连接后，频率按维度分开。
- 频道显示统计设备需求，包含缺频道的设备，因此可能出现红色 `33/32`；它不代表实际分配了 33 个频道。
- 界面打开时每 2 秒自动刷新在线数和频道数。相邻收发器不会直接互连，但仍可能通过共用线缆接入同一网络。

## 配置

编辑 `config/ae2wtx.cfg` 的 `wireless` 分类后重启；专服管理员可用 `/ae2wtx reload` 应用功耗与频率数量上限，跨维开关仍需重启。单人游戏也可在模组列表的 Config 中修改（无线设置在“无线”子页里）。

| 选项 | 默认值 | 作用 |
|---|---|---|
| `wirelessCrossDimEnable` | `true` | 允许跨维度连接 |
| `wirelessTransceiverIdlePower` | `10.0` | 每台收发器的空闲功耗，AE/t |
| `wirelessMaxBandsPerOwner` | `128` | 每位玩家的频率数量上限；关闭跨维后按维度计算 |
| `wirelessMaxBandsPerWorld` | `4096` | 世界存档的频率总数上限 |
| `pruneMissingTransceivers` | `true` | 所在区块已加载、但位置上已没有收发器的记录，自动从频率中清除 |

数量上限只限制新建频率；`0` 禁止新建，降低上限不会删除已有频率。这些上限与 AE2 频道容量无关。

`client` 分类只影响本机画面，在游戏内 Config 的第一页直接修改，点“完成”立即生效：

| 选项 | 默认值 | 作用 |
|---|---|---|
| `defaultTheme` | `dark` | 没单独选外观的收发器用深色（`dark`）还是浅色（`light`） |
| `panelOpacity` | `100` | 每面中央接线面板的不透明度（0~100%，按 10% 一档），调低可看清内部，0 为隐藏 |
| `glassArcs` | `true` | 是否在线时在玻璃上绘制电弧 |
| `renderEffects` | `true` | 是否绘制黑洞和光点 |
| `effectRenderDistance` | `32` | 在多少格内绘制黑洞和光点 |
| `simpleBlockModel` | `false` | 改用普通方块外观，不画机壳和特效 |
| `locateSeconds` | `60` | 定位高亮持续的秒数（5~600） |
| `locateThroughWalls` | `true` | 定位高亮是否透过方块显示 |

## 可选材质包

以下两个资源包含有不能随本项目分发的素材，需要用仓库里的脚本在本地生成（Python 3），生成在 `build/resourcepacks/`，放进客户端 `resourcepacks` 文件夹后启用：

- **旧版外观**：`python tools/packs/build_packs.py classic`，生成 `AE2WTX-Classic-Look.zip`，即 1.1.1 及以前版本的 ExtendedAE_Plus Light Mode 外观（C-H716、_leng、fish_旦）。启用后不显示黑洞特效。
- **高版本 AE2 拆卸音效**：`python tools/packs/build_packs.py sounds <Minecraft 的 assets 目录>`，从本机已有的 1.9 以上新版 Minecraft 资源中取出现代 AE2 扳手拆卸时的原版音效，生成 `AE2WTX-Modern-Sounds.zip`。不装这个包时，使用模组自带的近似合成音效。
