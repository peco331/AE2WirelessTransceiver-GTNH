# AE2 Wireless Transceiver (GTNH) · AE2 无线收发器

给 **GTNH 2.9.0-beta3 / Minecraft 1.7.10** 添加一个无线收发器：把基地的 **ME 网络接到远处的机器、仓库或其他维度**，省去中间的长距离线缆。

用法接近玩家熟悉的**量子网络桥（量子环）**：两地各放一个方块、接上 ME 线缆，再选同一个配对名称，就能连接两边的网络。本模组支持多个收发器使用同一个名称，不需要主端/从端切换，也不需要放入配对的奇点。

移植自 [ExtendedAE_Plus](https://github.com/GaLicn/ExtendedAE_Plus) 的无线收发器功能。本项目只提供这一类方块，不包含上游的全部功能。

A standalone GTNH 1.7.10 port of the ExtendedAE_Plus wireless transceiver. Link ME networks by a shared owner and band name, including across dimensions.

[下载 JAR](https://github.com/peco331/AE2WirelessTransceiver-GTNH/releases/latest) · [更新日志](CHANGELOG.md) · [技术文档与构建说明](docs/TECHNICAL.md) · [反馈问题](https://github.com/peco331/AE2WirelessTransceiver-GTNH/issues)

## 能做什么

- **远距离连接 ME 网络**：无线传递频道，让远处的 ME 接口、总线、终端等设备接入基地网络；默认允许跨维度，连接逻辑没有距离上限。
- **按名称配对，一组连接多台**：例如把基地和矿场的收发器都设成 `mining`。界面里把这个配对名称叫作“频段”。
- **分组管理**：在方块界面搜索、新建、选择、断开或删除频段；不同玩家放置的收发器按所有者隔离。
- **查看频道需求**：Waila 和方块界面显示频道、收发器数量、所有者及连接状态；缺频道的设备也计入，便于发现超载。
- **支持网络可视化工具**：查看 ME 网络时能看到同维度收发器之间的无线连线及频道负载，方便排查连接。
- **扳手锁定与拆卸**：支持 GT 扳手和 AE2 石英扳手；锁定后，普通玩家不能修改或直接挖掉别人的收发器。
- **模型与语言**：兼容 GTNHLib 时使用 3D 模型及发光动画；缺少兼容的模型 API 时使用普通方块外观。提供简体中文、繁体中文和英文。

## 安装与适配版本

把 Release 中的 `ae2wtx-*.jar` 放入实例的 `mods` 文件夹；联机时客户端和服务端都需要安装同一版本。更新时移走旧版本 JAR，避免同时加载两份。

| 项目 | 本项目的目标版本 / 用途 |
|---|---|
| 整合包 | **GTNH 2.9.0-beta3**，Minecraft 1.7.10 / Forge |
| Applied Energistics 2（必需） | GTNH 分支 `rv3-beta-1050-GTNH` |
| GregTech 5 Unofficial（必需） | `5.09.54.133`，提供配方和 GT 扳手支持 |
| GTNHLib（可选增强） | 目标版本 `0.11.46`，提供 3D 方块模型；无兼容 API 时回退为普通方块 |
| Waila（可选） | 目标版本 `1.19.34`，提供准星指向方块时的信息提示 |

支持单人游戏和专用服务器。以上是本项目使用的适配基线；其他 GTNH 版本尚未在此声明兼容。请使用整合包自带的核心依赖，不要为了安装本模组单独替换 AE2 或 GregTech。

## 合成

在工作台中使用 **8 个 ME 量子环 + 1 个 ME 量子链接仓**，合成 **1 个无线收发器**：

```text
量子环    量子环      量子环
量子环    量子链接仓  量子环
量子环    量子环      量子环
```

这是合成材料，不需要在世界中搭成 3×3 量子环结构。连接两地至少需要两个收发器。

## 快速上手：把矿场接到基地 ME 网络

1. 在基地放置一个收发器，用 ME 线缆连接已有的 ME 网络。
2. 空手右键打开界面，在搜索框输入 `mining`，点击 **新建**。新建后，这台收发器会直接加入该频段。
3. **由同一位玩家**在矿场放置另一台收发器，用 ME 线缆连接矿场的 ME 设备。
4. 打开矿场收发器界面，选择 `mining`，点击 **设定**。
5. 保证两地相关区块加载，并为 ME 网络提供足够的 AE 能量。需要 32 频道路径时，检查接入路径是否使用致密线缆。

```text
基地 ME 网络 ── ME 线缆 ── 收发器 [mining]
                                  ⋮ 无线连接
矿场 ME 设备 ── ME 线缆 ── 收发器 [mining]
```

可以继续把其他收发器加入 `mining`。同名收发器连接的是同一个 ME 网络，原本独立的网络也会因此合并；搭建子网时仍要按 AE2 的方式隔离网络。

### “频段”和“频道”有什么区别？

| 名称 | 玩家需要知道的含义 |
|---|---|
| **频段** | 本模组的配对名称，相当于给一组无线连接起名，如 `mining`、`storage`。名字相同且所有者相同才会连接。 |
| **频道** | AE2 的网络资源。接口、总线、驱动器等设备要取得频道才能正常工作；给频段改名不会增加频道。 |

频段名支持字母（包括中文）、数字、下划线 `_` 和连字符 `-`，最长 64 个字符；区分大小写，不支持名称中间的空格。

关闭跨维度连接后，同名频段还会按维度分开。当前没有 FTB Teams 队伍共享：两位玩家各自放置的收发器，即使名字一样也不会互连。多人共同建设时，请让同一位玩家放置需要互连的收发器。

### 界面按钮

| 按钮 | 作用 |
|---|---|
| 新建 | 使用搜索框中的名称创建频段并让本机加入；名称已存在时直接加入。 |
| 设定 | 把本机切换到列表中选中的频段。 |
| 断开 | 只让本机退出当前频段，保留频段和其他收发器。 |
| 删除 | 删除所选频段并断开其关联收发器；只能由所有者或管理员执行。可多选删除；未选择列表项时使用搜索框中的名称。 |

删除频段时，已加载的收发器立即清空配对；未加载的收发器在以后加载时处理清理。当前版本在异常退出、存档只完成部分保存时仍存在恢复旧配对的边界问题，因此不承诺所有异常场景下删除绝不会回滚。

### 扳手操作

| 操作 | 效果 |
|---|---|
| 空手右键 | 打开频段管理界面。 |
| 手持扳手右键 | 锁定 / 解锁；已锁定设备只允许所有者或管理员解锁。 |
| 手持扳手，潜行右键 | 拆卸并掉落方块；已锁定设备只允许所有者或管理员拆卸。 |

未锁定收发器允许其他玩家操作。相邻的两台收发器不会直接连在一起，但仍可能通过共用的 ME 线缆接入同一网络。

## 频道、供电与区块加载

**收发器是连接网络的方块，不会凭空生成频道。** 它本身不占用频道，具有致密线缆级别的 **32 频道容量**；实际设备能拿到多少频道，仍受 ME 控制器、沿途线缆、其他网络组件和 AE2 路径分配限制。中间经过只能传递 8 频道的普通线缆或组件时，仍会出现 8 频道瓶颈。

显示的 `/32` 是收发器的容量，不代表整条路径一定能提供 32 个频道。关闭 AE2 的频道限制后，频段容量显示为 `∞`；这一设置属于 AE2，而不是本模组的频段数量上限。

- **默认功耗**：每台收发器空闲消耗 **10 AE/t**，另加连接网络中其他设备的消耗；当前不会按无线距离加收功耗。
- **区块加载**：本模组不提供区块加载功能。基地、远端收发器及沿途网络设备需要保持加载；跨维度连接也一样。
- **安全权限**：连接仍遵守 AE2 的安全检查。连接到有安全终端保护的网络时，要确认收发器所有者的权限。

### 怎么看频道数字？

本模组的频道数字主要用于检查**设备需要多少频道**，包含尚未取得频道的设备。比如一条分支挂了 33 个各需一个频道的设备，会显示红色 **33/32**，方便发现超载；这不表示已经成功分配了 33 个频道。

“本频段频道”汇总该频段各收发器本地分支的需求，用于观察负载，不等同于 ME 控制器的剩余频道数，也不是给每台收发器新增的一份频道额度。需求达到容量时显示黄色，超过时显示红色。

用 AE2 的**网络可视化工具（Network Visualization Tool）**右键网络组件，可检查连接和频道路径。本模组补充当前维度内收发器之间的无线连线；跨维度连接不会画成一条跨世界的 3D 线。Waila 的“设备在线”表示无线连接已建立，机器能否工作还要检查供电和频道。

## 配置

配置文件为 `config/ae2wtx.cfg`，以下选项都在 `wireless` 分类下：

| 选项 | 默认值 | 作用 |
|---|---|---|
| `wirelessCrossDimEnable` | `true` | 允许跨维度连接；修改后必须完整重启游戏 / 服务端。 |
| `wirelessTransceiverIdlePower` | `10.0` | 每台收发器的空闲功耗，单位 AE/t；必须为有限非负数。 |
| `wirelessMaxBandsPerOwner` | `128` | 每位所有者最多创建多少个频段，范围 `0..10000`；跨维开启时全维度共用，关闭时按维度计算。 |
| `wirelessMaxBandsPerWorld` | `4096` | 一个世界存档最多创建多少个频段，范围 `0..100000`。 |

两个数量上限限制的是**频段数量**，不是 AE2 频道数量或收发器数量；只在新建频段时检查。`0` 禁止新建，降低上限不会删除已有频段，也不妨碍加入已有频段。非法功耗恢复为 `10.0`；数量上限越界时会钳制到允许范围。

推荐编辑配置文件后重启。专用服务器管理员也可以执行 `/ae2wtx reload`，应用功耗和频段数量上限的改动；跨维开关仍需重启。

## 当前使用限制与排查

- **界面信息可能停留在旧值**：目前频段界面没有定时刷新；外部设备或连接改变后，可重新打开界面获取新信息，Waila 可查看方块同步状态。
- **游戏内 Config 保存存在问题**：当前事件处理可能用文件中的旧值覆盖刚修改的值，请通过配置文件修改，再重启或在专服执行重载命令。
- **外观只有开 / 关两态**：没有移植上游的全部频道外观；详细频道信息由界面、Waila 和网络可视化工具提供。

遇到不连通或设备不工作，依次检查：**同一所有者和频段 → 区块加载 → 供电 → 频道路径 → AE2 安全权限**。本模组连接的是方块组成的 ME 网络；手持无线终端的接入范围和配对仍由原来的无线接入点 / 终端功能负责。

反馈问题时，请提供 GTNH 与本模组版本、单人或服务器环境、复现步骤和相关日志；分享日志前移除私人信息。
