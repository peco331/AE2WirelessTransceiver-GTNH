# Third-party notices

AE2 Wireless Transceiver (GTNH) is an LGPL-3.0 port and adaptation of the wireless transceiver from
[ExtendedAE_Plus](https://github.com/GaLicn/ExtendedAE_Plus), created by GaLicn and contributors.
See that project's repository for its source, copyright notices, and license history.

The block model, textures and GUI texture are original to this project and are generated by
`tools/art/generate_assets.py`. Earlier releases (1.1.1 and before) adapted the ExtendedAE_Plus Light Mode
Texture Pack (1.21), credited to C-H716, _leng, and fish_旦; none of those assets remain in this
repository's current tree. `tools/packs/build_packs.py classic` rebuilds them from Git history into a local,
optional resource pack; that pack is not distributed with this project.

The wrench-disassembly sound in the mod jar is synthesised by `tools/art/generate_sounds.py`.
`tools/packs/build_packs.py sounds` copies Minecraft's own `entity.item_frame.remove_item` sounds (the ones
modern AE2 plays) from the player's local Minecraft assets into a local resource pack; Mojang's audio is
never part of this repository or its releases.

The project compiles against Applied Energistics 2 Unofficial, GregTech 5 Unofficial, Waila, Minecraft
Forge, and SpongePowered Mixin. These dependencies are
not embedded in this mod jar; their respective source repositories and distributions contain their
copyright and license terms.
